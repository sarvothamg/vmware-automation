# VMware Automation

VMware infrastructure automation examples using Ansible and PowerCLI.

This repository demonstrates common VMware vSphere automation tasks performed by Infrastructure Engineers.

## Technologies

- VMware vSphere
- Ansible
- PowerCLI
- PowerShell
- YAML

---

## Ansible Automation

Location:

```
playbooks/
```

Includes:

- Collect Virtual Machine Information
- Power On Virtual Machines
- Power Off Virtual Machines
- Create Snapshots
- Delete Snapshots
- Clone Virtual Machines
- Datastore Information
- Cluster Information
- Create VMware Folders

---

## PowerCLI Automation

Location:

```
powercli/
```

Includes:

- Connect to vCenter
- Get VM Inventory
- Power On Virtual Machines
- Power Off Virtual Machines
- Create Snapshots
- Remove Snapshots
- Clone Virtual Machines
